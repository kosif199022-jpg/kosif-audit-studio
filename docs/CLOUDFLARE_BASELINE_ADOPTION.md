## الإضافات

- نقل وظائف الإيجنت المحلي من إصدار KOSIF 4 إلى طبقة متوافقة مع بيانات React الحالية.
- خطط مخاطر وإكمال، مسؤول وموعد ومبرر لكل مهمة، سجل انتقالات وآخر خمس خطط.
- محادثة مستندة إلى الملف مع مصادر وبصمة تغير؛ إملاء وقراءة اختياريان.
- مسودات مذكرات قابلة للتحرير والتنزيل تحتفظ ببصمة مصدرها الأصلي، حتى بعد حفظها لاحقًا.
- مرصد مصادر رسمية مع تواريخ السريان بحسب بداية الفترة ومحفوظات المراجع.
- تسعة تخصصات لأسئلة التحدي، مع إبقاء المجلس الحالي وقراراته البشرية وبواباته.
- العمل دون اتصال لأصول التطبيق العامة فقط؛ لا تخزين مؤقت لواجهات API أو البيانات أو روابط تحمل استعلامات.

الثيمات الثلاثة وملفات CSS الأصلية وصور الواجهة والخطوط وبوابات التقرير
ومحرك الحسابات والملفات المرفقة محفوظة. الإضافات تستخدم متغيرات الثيم الحالية.
حالة الإيجنت ضمن حالة الارتباط المحلية وتدخل في تصدير JSON الحالي؛ استعادة
JSON تبقى وفق عقد المصدر الأصلي: بيانات خام فقط، دون إعادة اعتماد قرارات قديمة.

## النشر

فرع النشر: `codex/preserve-theme-cloudflare`.

أمر Cloudflare Pages: `npm run build:cloudflare`.
مجلد النشر: `dist/client`.

يمر النشر بالبناء والاختبارات قبل إعداد Worker. يبقى `worker/index.js` الأصلي
كما هو؛ تضيف حزمة Cloudflare غلافًا يزيل ترويسة هوية Sites من طلبات الإنترنت،
لأن هوية تلك الترويسة موثوقة فقط خلف Sites. واجهات API ترفض الطلبات غير
الموثقة. وظائف الواجهة المحلية تعمل كما كانت؛ هذه العملية لا تنقل قاعدة بيانات
ولا مفاتيح مزودين من حساب Sites الأصلي. بيانات المستخدم المحلية لا تنتقل بين
النطاقات تلقائيًا؛ يمكن نقل الميزان عبر لقطة JSON الحالية، وإرفاق الأدلة محليًا
في النطاق الجديد عند الحاجة.

ملف `.openai/hosting.json` محفوظ للتوافق مع المشروع الأصلي؛ لم ينشر هذا التغيير
فوق رابط Sites الأصلي. فرع `main` مختلف البنية ولا يستخدم تلقائيًا كأساس لهذا النشر.
