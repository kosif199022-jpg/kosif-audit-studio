## حوكمة البيانات

- كل بيانات الشركة والأرصدة الحالية اصطناعية ومخصصة للعرض والاختبار.
- يعمل التطبيق من دون خادم؛ يحفظ بيانات الحالة الوصفية في `localStorage` ومحتوى الأدلة المرفوعة في IndexedDB. الميزان المستورد مؤقت للجلسة ولا يُستعاد بعد إعادة التحميل؛ يمكن تنزيل لقطة JSON وCSV قبل ذلك.
- لا تحتوي الحزمة على قاعدة بيانات حقيقية، أو تكامل ERP/بنك، أو مزامنة مستخدمين، أو RBAC، أو سجل تدقيق مركزي. القفل والبصمات الحالية ضوابط عرض محلية قابلة للتحقق وليست ضمانات تخزين مؤسسي.
- بيانات المعايير داخل التطبيق ملخصات وبيانات وصفية؛ يجب الرجوع إلى المصدر الرسمي الأحدث والمتطلبات السعودية السارية قبل اتخاذ قرار مهني.

## قابلية التحقق

تغطي الحزمة الآلية توازن الوحدات الصغرى، وعدد الحسابات والمجالات، وصحة مراجع الجولات والمعايير، وحالات الربط، واستيراد XLSX، وبصمة بايتات الأدلة والتزام مجموعة البيانات، وإبطال الحالة عند تغيير البيانات، ورفض حالات التقرير الفاسدة، وتجميع التغطية والتحليلات. يُثبت العدد النهائي بعد بوابة الإصدار. تشغيلها:

```bash
npm test
```
