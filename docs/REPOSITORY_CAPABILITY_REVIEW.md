# مراجعة قدرات مستودعات KOSIF

فُحصت الأشجار الحالية للمستودعات المتاحة ملفًا ملفًا، بما فيها المصدر والاختبارات والمهاجرات والوثائق والإعدادات. الهدف كان استخراج الأنماط القابلة لإعادة البناء داخل Audit Studio، لا نسخ مستودعات كاملة أو تمرير ادعاءاتها التجريبية على أنها قدرات إنتاجية.

قُرئت جميع الملفات النصية في الأشجار الحالية للفرع الافتراضي. الأصول الثنائية والحاويات سُجل نوعها وحجمها ومسارها ولم تُعامل كنص مصدر. لا يشمل هذا الفحص تاريخ Git أو الفروع غير الافتراضية أو أسرار المنصة المخزنة خارج المستودعات.

## خلاصة القرار

| المستودع | القيمة الأساسية | قرار الدمج |
| --- | --- | --- |
| `sky` | نواة محاسبية دقيقة، حوكمة بيانات، RLS/RBAC، أدلة، استيراد، تسويات، تقارير ومعرفة | المرجع المعماري الأقوى؛ نُقلت أنماط الوحدات الصغرى والبوابات والأثر، بينما تبقى قاعدة البيانات المؤسسية مرحلة خادم لاحقة |
| `mahmoud1990` | محركات تدقيق ومواد معيارية ومجلس متعدد المقاعد وتقارير وتصدير | أُعيد بناء المجلس والعينة والبصمات والربط مع فصل السلطة البشرية؛ لم تُنقل أخطاء netting أو sampling أو endpoints العامة |
| `Acc` | تكامل accounting/audit/evidence واختبارات حتمية واسعة | استُخدمت أفكار التحقق، سلاسل الأدلة، التسويات وبوابات التقارير، لا تخزين KV أو assertions من العميل |
| `smart-trial-balance-review` | رحلة إدخال → ربط → جولات/PBC → تقرير، وتجربة RTL واضحة | نُقلت الرحلة ومنطقة التحضير والمجلس والجولات؛ لم يُنقل مفتاح Gemini المحلي أو قرار الإكمال غير الحتمي |
| `mafateeh-al-tharwa` و`mafateeh-al-tharwa2` | ingest قابل للاستئناف، مراجع صفحات، annotations، export، mobile/RTL/PWA | نُقلت أنماط provenance والربط والواجهة المتجاوبة؛ لم تُنقل تحولات build المتسلسلة أو الأمن الضعيف أو المحتوى غير المرخّص |
| `aurora-finance` و`moon` | بطاقات ومؤشرات وهوية بصرية عربية | إلهام بصري فقط؛ لم تُنقل الأرصدة والادعاءات hardcoded أو ختم «مجلس AI» الوهمي |
| `kosif-audit-studio` على GitHub | مستودع فارغ وقت الفحص | لا مادة قابلة للدمج |
| `-` | بيان رؤية موجز | مرجع صياغة فقط |
| `CLOUDFLARE_API_TOKEN` | مستودع فارغ ذو اسم خطر | لا دمج؛ يُنصح بإعادة تسميته ومنع إيداع الأسرار فيه |

## القدرات التي أصبحت فعلية في التطبيق

- تحضير XLSX/XLS/CSV/TSV/TXT قبل الالتزام، مع أرقام عربية وفارسية، تكرارات، إشارات، وحدات صغرى وتوازن دقيق.
- ميزان عرض حتمي من 5,000 حساب، و20 مجالًا، و58 موضعًا معياريًا تشغيليًا، وربط قابل للمراجعة بمعايير وتأكيدات ومخاطر وإجراءات وأدلة.
- 20 جولة و20 طلب PBC و20 ملاحظة مترابطة، مع جولة متابعة لا تُضاف إلا بعد اعتماد بشري.
- رفع دليل فعلي داخل الجلسة وحساب SHA-256 من بايتاته؛ يُحفظ المحتوى محليًا في IndexedDB ويُعاد فحص حجمه وبصمته قبل الاعتماد والتصدير، بينما يبقى خارج JSON ولا يُرسل إلى خادم.
- عينة مخاطر قابلة لإعادة الإنتاج، 60% منها موجهة بالمخاطر والقيمة.
- سلسلة قيود اختبارية ببصمات SHA-256، والتحقق من العبث، وحالات تسوية بنكية بلا ترحيل تلقائي.
- قفل فترة بقاعدة شخصين، وإعادة فتح موثقة تلغي اعتماد التقرير السابق.
- مجلس تحليلي من أربعة مقاعد؛ يحفظ اللقطة والتوافق، بينما يبقى اعتماد الخطة واختيار الرأي وإصدار التقرير قرارات بشرية منفصلة.
- 12 بوابة تقرير fail-closed تشمل القبول، التوازن، الربط، مراجعة التحليلات، قفل الفترة، قرار المجلس، الجولات، الأدلة، الملاحظات، التسويات، نوع الرأي والاعتماد البشري؛ وتتحقق من العلاقات والتسلسل الزمني لا الأعداد وحدها.
- تغيير مجموعة البيانات يفتح الجولات والأدلة والنتائج والتسويات ويلغي اعتماد التقرير، ويمنع اعتبار عمل مؤرخ قبل الالتزام بالمجموعة الجديدة صالحًا.
- دليل مسار من سبع خطوات متجاوب مع الجوال، و10 مراحل تشغيل، و12 بوابة fail-closed، و13 قسم تنقّل، ومركز نتائج موحد، وتنزيل JSON وCSV للجلسة، وPDF من 15 صفحة وXLSX من 12 ورقة تتضمن 11 فحص مصالحة لبيانات العرض الإصدار v7.

## قدرات مؤجلة عمدًا

- قاعدة بيانات متعددة المستأجرين، RBAC، SSO، تشفير مركزي، سجل WORM وlegal hold.
- استخراج محتوى PDF/DOCX وOCR، وفحص البرمجيات الخبيثة، ورفع الأدلة إلى مخزن خادمي دائم قابل للاستئناف. الحفظ الحالي محلي في IndexedDB ولا يوفّر retention مؤسسيًا.
- تكامل ERP أو بنك فعلي، أو ترحيل قيود، أو مصادقات خارجية.
- مزود AI حي أو أسرار API في المتصفح. المجلس الحالي محرك تحليلي حتمي قابل للاختبار، لا نموذجًا يصدر حكمًا مهنيًا.
- نصوص IFRS/ISA الكاملة أو ادعاء تحديث تشريعي آلي؛ الموجود ملخصات تشغيلية تتطلب الرجوع للمصادر الرسمية.

## حدود الثقة

النسخة الحالية تطبيق متصفح مستقل. تحفظ بيانات الحالة الوصفية في `localStorage` وبايتات الأدلة المرفوعة في IndexedDB، ويمكن للمستخدم المحلي تعديل المخزنين أو مسحهما. يعاد التحقق من الدليل المحلي عند الاعتماد والتصدير، لكن لا يوصف القفل أو سجل القرارات بأنه غير قابل للتغيير على مستوى المؤسسة، ولا يُستخدم التقرير بديلًا عن إجراءات المراجع المرخّص أو أنظمة حفظ ملفات التدقيق المعتمدة. الميزان المستورد خاص بالجلسة؛ التنزيل المؤقت هو وسيلة الاحتفاظ به قبل إعادة التحميل وليس استعادة آلية.

## مراجعة تطبيقَي KOSIF v2 وv3

تمت مراجعة واجهتي Workers العامتين مباشرة في 28 أغسطس 2026. تعذّر فتح صفحات Cloudflare Dashboard بسبب حلقة تحقق آلية، لذلك لم تُستخدم أي بيانات تشغيلية أو إعدادات حساب خاصة، واعتمدت المقارنة على الواجهتين العامتين فقط.

| القدرة المرصودة | القرار في Audit Studio |
| --- | --- |
| هوية v3 البنفسجية الفاتحة | جُعلت المظهر الافتراضي مع الحفاظ على أسلوب KOSIF العربي |
| هوية v2 البنفسجية الداكنة والذهبية | أُضيفت كمظهر اختياري |
| وضع السينما في v3 | حُوّل إلى وضع عرض تنفيذي لا يغيّر حالة الارتباط |
| واجهة Gemini / OpenAI / Claude | حُوّلت إلى سجل حالة صريح؛ KOSIF المحلي فقط نشط والبقية غير مهيأة |
| مؤشرات المسار في v2 والصورة المرفقة | بُني دليل واضح من سبع خطوات، مع إبقاء المراحل التشغيلية وبوابات الإصدار الاثنتي عشرة منفصلة |
| 5,000 حساب في v2 و330 حسابًا في v3 | احتُفظ بسيناريو Audit Studio من 5,000 حساب؛ لا تُخلط مجاميع مجموعات أو عملات مختلفة |
| 20 جولة في v2 وv3 | بُنيت 20 جولة مكتملة ومختبرة، وكل جولة مرتبطة بدليل ونتيجة ومعايير واستنتاج |
| مكتبة الكتب | لم تُنسخ مواد محمية؛ استُخدم مركز المعايير والروابط الرسمية فقط |

### نتائج المقارنة الحية

- **v2:** 5,000 حساب، إجمالي مدين ودائن 2,544,568,750 ريال، 20 جولة و20 نتيجة و40 اسم مرفق و4 تسويات. لم يتضمن التصدير محتوى الأدلة أو بصماتها أو مراجعيها. سبقت كل الجولات اعتماد الميزان، وظهر التقرير بعد الاعتماد بـ79 ملّي ثانية؛ لذلك استُخدمت الأرقام كمرجع قدرة لا كمرجع حوكمة.
- **v3:** المجموعة الحالية 330 حسابًا وإجمالي 880,943,250، بينما حمل التصدير تقريرًا قديمًا لمجموعة 110 حسابات وإجمالي 533,905,000. بقيت 19 من 19 طلبات PBC غير مستوفاة، ومع ذلك ظهر التقرير صادرًا؛ كما لم تطابق أسطر التسويات أسماء الحسابات الحالية.
- **Audit Studio v7:** عينة مستقلة من 5,000 حساب وإجمالي 1,107,323,928.55 ريال، مع 20 جولة و20 دليلًا و20 نتيجة و3 قيود مزدوجة وكتالوج 58 معيارًا و12 بوابة. أضيف جسر التسويات، ميزان معدل، مصدر رقم واستمرارية تحليلية؛ أما الحفظ المؤسسي وRBAC/RLS وسجل WORM فيتطلب خادمًا لاحقًا ولا يُدعى وجوده الآن.

تشمل الإضافة كذلك تنقل جوال يصل إلى 13 قسمًا، وتقرير PDF من 15 صفحة وملف Excel من 12 ورقة يتضمن 11 فحص مصالحة لبيانات العرض الاصطناعية v7، مع إبقاء JSON المحكوم والطباعة الحية خاضعين لحالة الارتباط الحالية وبواباتها. يبقى JSON المؤقت وCSV متاحين لتنزيل بيانات الجلسة حتى عندما تكون مسودة.
